# 数字人大屏交互验证记录

日期：2026-10-20。范围：本地 Vue 原型，非真实硬件或厂商在线会话。浏览器实测使用管理端真实入口；长文、显隐组合及横屏使用 `tests/interaction-preview.html` 的独立夹具，不读写客户场景存储。

## 自动验证

- `node --test tests/interactionController.test.ts tests/idleSession.test.ts`：13项通过。涵盖提交校验、重复提交、流式切换、中断后的迟到返回、错误恢复、无答案、识别结果确认与取消、结束/卸载清理、反馈互斥、历史上限、回答中语音不可用，以及闲置边界、继续使用保留输入、处理期间不清屏和后台延迟后的过期。
- `npm run build`：通过。仍有项目已有的 Vite 配置兼容性和包体积提示；构建并不等于完整 Vue 模板类型检查或实体机验收。

## 浏览器走查

| 验证项 | 实测结果 |
| --- | --- |
| 场景配置 → 交互预览 | 可打开全页预览；有本地演示说明；背景/人物/Logo使用当前机器配置 |
| 文字提问 | 提交后立即显示问题、等待提示和停止按钮，输入与发送在等待阶段禁用 |
| 正常回答 | 内容逐段显示，完成后出现反馈；点赞后 `aria-pressed=true` |
| 快捷入口与返回 | 使用机器现有按钮标签和触发文本；快捷区与对话可往返；会话仍在 |
| 停止回答 | 保留部分回答，显示“已停止”，提供重试和换问题 |
| 未命中 | 显示未找到相关内容和恢复操作，不伪造知识答案 |
| 服务故障及重试 | 错误可见；重试后问题气泡仍只有1个，没有重复插入失败轮次 |
| 超时 | 出现等待超时文案及重试入口 |
| 语音不可用 | 提示可使用文字或快捷问题，文字入口仍可用 |
| 短按和模拟识别 | 短按提示时间过短；按住600ms后进入识别，随后将当前提问预演文案填入输入框，等待确认发送；没有真实录音 |
| 主动结束 | 等待中结束后返回待机，问题、历史及输入清空 |
| 闲置清除 | 实测闲置超过60秒后输入和对话清空，返回待机；不把会话记录写入场景 |
| 倒计时继续 | DOM观察到末尾倒计时与继续按钮；抽离可注入时钟的闲置逻辑，验证50秒提示、55秒继续后保留输入、重新计时及到期只清除一次；按钮隔离父容器pointerdown/keydown，避免提前卸载 |
| 关闭重开 | 从真实场景入口退出再进入，恢复待机、清空输入，编辑器仍没有默认选中图层 |
| 长回答 | 夹具回答使容器 `scrollHeight=2487`、`clientHeight=211`，页面无横向溢出；Home回到顶部后出现“查看最新回答”，点击可回到底部 |
| 关闭区域 | 同时关闭对话/字幕/快捷区时，对应DOM均为0，服务错误仍在输入区可见 |
| 窗口适配 | 在1280×720、1024×768、640×720检查；文档宽度与窗口一致，屏幕按比例缩放。横屏1920×1080夹具可提问，未修改保存场景 |
| 初次打开 | 修正Drawer延后挂载导致ResizeObserver未绑定、画布缩成极小尺寸的问题 |

## 尚需真实环境验证

- 真实ASR、权限拒绝、降噪、声学回声、VAD误触发及多语言识别。
- 真实知识库正确率、客户隔离、流式接口、播报音画同步、停止确认、断线重连、设备下发。
- 实体屏幕的安装高度、触点物理尺寸、阳光反光、不同人群可达范围；横竖屏应分别配置适合的内容位置，保持比例不等于自动重排全部已保存元素。
