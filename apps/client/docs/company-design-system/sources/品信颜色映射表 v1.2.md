### 1.2 CSS 映射规则

本文件将完整 Figma 路径转成小写，并将 `/` 替换成 `-`，前面加 `--`。例如 `color/orange/6` → `--color-orange-6`，`color/text/brand/1` → `--color-text-brand-1`，`color/grey/white` → `--color-grey-white`。中文不进入代码变量名。
