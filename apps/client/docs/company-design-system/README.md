## 4. 颜色引用约定与待确认项

组件优先引用 `--color-fill-*`、`--color-text-*`、`--color-border-*`、`--color-bg-*`、`--color-icon-*`，不在各处重复写HEX。需要语义组未提供的原始色阶时，可引用对应基础变量并说明用途。

- 原文品牌蓝与CSS的 `--brand`、`--color-brand-6` 均为 **#0468FE**；用户历史对话另指定过 **#0481FE**。用户确认本文件为公司规范并要求直接应用后，本次管理端采用v1.2文件的 **#0468FE** 及其完整色阶，实施时已明确告知。原始文件保持原样。
- `--color-fill-neutral-5` 别名是 `grey/3`，实际 **#525E71**；描述中却有“极浅填充、卡片hover”。暂不将它用于浅底卡片hover。此类hover使用原文明确定义的 `fill/neutral/1`。
- 颜色表保留brand/ai/state各组的disabled别名，但按钮专项明确规定实体按钮禁用用中性灰；按钮实现以专项规则为准。
- Bg1～5均为白色是原文定义，保留其语义名称，不擅自改成不同灰阶。
- `cyan/6`为#04C0FE、`accent/6`为#04FCE6；AI色使用`ai`，不要用`accent`替代。

## 5. 管理端与终端范围

管理端以1440×900为验收基准。适应窗口高度时保留可读字号、padding和固定操作区，通过合理分区或内容区滚动解决溢出，不能靠压小所有控件硬塞。

大屏为原生1080×1920的独立画布，整屏等比缩放；对话字号28px、输入24px、金刚区20px，图标按用户专项40/48px等配置。终端以语音为主、点击辅助，不依赖hover。公司管理端32px控件高度和14px正文不直接移植到终端。

场景配置的右侧表单、开关、参数输入、分类导航使用品信规范。画布、交互预览及右侧光球/问答/输入效果预览使用原有独立终端规范；由`data-scene-presentation`划定边界，共享管理端样式必须排除边界与后代。`src/scene-presentation-theme.css`恢复终端的默认继承值，组件自身颜色、动效、字号和保存的场景设置优先，不因管理端主题变更而改变。
