# 用户端统一弹窗规范

按设计师要求，当前用户端所有 Dialog 与确认弹窗使用同一外框，不按内容另设尺寸档位。

设备配置的人设选择、音色选择为设计师后续指定的例外：共用1120×720px大弹窗，宽高分别限制在视口减48px以内。左侧28%展示人物预览、人设描述与音色选择，右侧展示已有选项；窄屏改为上下布局。只复用已有数据与试听操作，不加入生成、上传或额外筛选字段。页面仅展示当前已选择的人设与音色。

- 标准尺寸：520×640px。
- 实际宽度：`min(520px, 100vw - 32px)`；实际高度：`min(640px, 100dvh - 48px)`。
- 页面缩放或视口变化时自动重新计算；切换标签、增加内容不会改变外框尺寸。
- 居中显示，4px圆角，白色背景；标题18px、24px行高、左对齐。
- 标题、内容、底部操作区内边距统一16px。标题和底部操作区固定，长内容在内容区内部滚动。
- 表单控件不得超出内容宽度；原有宽表单改为纵向排列。
- 底部操作右对齐，按钮间距12px；保留各业务现有操作与文案。
- 统一样式入口：`src/client-dialog-standard.css`。业务组件不得覆盖外框宽高。

## 充值弹窗

- 移除对公汇款；在线充值与扫码支付使用两级面包屑，可返回在线充值修改金额。
- 自定义金额使用 Element Plus 数字输入框，支持两位小数和步进操作。
- 去支付按钮仅显示文字。
- 支付宝选项及去支付按钮适配内容区宽度，提示位于按钮下方。点击去支付进入扫码展示，原型使用演示二维码，不直接记入余额。
- 在线充值展示以下两条提示：
  1. 充值金额仅用于调用 API 服务，网页版及 App 对话免费使用，无需充值。
  2. 充值后可以前往账单页面开具发票。
