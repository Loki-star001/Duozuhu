# 用户端组件规范与通用设置布局说明

适用项目：虚拟人管理平台。适用范围：当前用户端可访问页面。任务目标：管理数字人大屏的机器。

本规范以保留现有业务内容为原则。按用户最新要求，将设备控制与设备配置合并为“设备配置”入口；其余平台名称、菜单、字段、表头、按钮、提示文字及数据保持原样。此次实施调整组件样式及通用设置布局。新增字段、增删功能或修改文案应先作为产品建议交给设计师决定。

## 1. 规范来源

- Element Plus 提供一致性、反馈、效率和可控性的设计原则，以及组件尺寸和状态参考。
- 当前用户端使用 Vue 3、Pinia 和 Element Plus。保留品牌色 `#165DFF` 与现有业务命名，Element Plus 通过主题变量对齐项目设计规范；未开放的旧模块不在本轮改版范围内。
- 224px 主侧栏、56px 二级导航、48px 表格行高和下述百分比布局属于本项目约定，并非所有数值都来自官方默认值。

官方参考：[设计原则](https://element-plus.org/zh-CN/guide/design.html)、[按钮](https://element-plus.org/zh-CN/component/button.html)、[表格](https://element-plus.org/zh-CN/component/table.html)、[弹窗](https://element-plus.org/zh-CN/component/dialog.html)、[标签页](https://element-plus.org/zh-CN/component/tabs.html)。

## 3. 通用设置的需求分析

用户的主要操作是先确认目标机器，再编辑这台机器的应答、配置和场景，或执行现有设备控制操作。因此保留机器列表有助于减少来回切换页面，也能让当前对象一直可见。

人设配置使用现有的人设列表，代表选择要编辑的人设；不把它擅自改成机器列表，不新增“分配”流程和按钮。

### 共用布局

- 机器列表占通用设置可用区域的 **22%**，右侧内容占剩余区域。
- 正常桌面尺寸仅设 **220px最小宽度**，没有固定宽度或固定最大宽度。
- 浏览器宽度不超过1100px时，列表最小宽度为200px；列表仍按22%计算。
- 左右区域分别滚动。保留机器名称、状态、机器码、搜索和刷新等已有内容。
- 保留原有“当前机器”展示位置，不额外增加说明栏、统计卡或操作入口。

百分比以扣除224px主侧栏后的内容区计算，不以整个屏幕计算。例如1280px视口时列表约232px；1920px视口时约373px。这些尺寸由比例计算得出，不是固定值。

### 各页面的布局调整

| 页面 | 布局处理 | 内容约束 |
| --- | --- | --- |
| 设备配置（合并原设备控制） | 共享机器列表及“当前机器”上下文；左侧保留模式、音量与设备控制，右侧先选人设再选音色；返回内容选择作为音色区底部的一行控件 | 人设选择同时承担形象切换，只保留一份人设选中状态；不再提供独立换形象入口或独立返回内容卡片 |
| 设备应答 | 保留开机自我介绍、打招呼、语言切换提示词；标签栏统一为下划线选中态；多语言编辑区域使用一致卡片和输入尺寸 | 不新增语言、话术类型、开关或保存按钮 |
| 人设配置 | 左侧人设列表同样按22%伸缩；右侧编辑内容利用剩余空间；原保存按钮右对齐 | 不改人设名称、说明内容和按钮用途 |
| 场景配置 | 机器列表后，预览与设置区按56% / 44%分配；设置区最小280px；宽度不足时改为预览在上、设置在下 | 保留画布、布局设置、设备背景、Logo配置、金刚区配置及原有选项 |
| 费用－用量信息 | 主内容区全宽，页面内边距24px／20px；余额与消费等宽展示；导出与充值并列置于顶部右侧，月份选择留在每月用量区；图表随剩余页面高度伸展，并保留最小高度 | 保留原字段、金额、月份选项、充值和导出功能 |

## 4. 产品走查建议：先记录，暂不实施

设备控制与设备配置已按用户要求合并为“设备配置”入口。原控制入口的内部导航标识兼容同一页面；其他字段、操作文案和生效规则保持原样。机器列表继续按22%伸缩，只设最小宽度。

Vue 合并页面复用当前音色、人设和返回内容组件，并恢复原设备控制区。确认弹窗与成功提示使用 Element Plus；机器列表只保留一份，原操作文案保持不变。

以下事项涉及交互或业务行为，不属于本轮组件样式与布局修改：

- 音色选择目前有说明文字但没有实际选项，是否补充控件由设计师确定。
- 新增人设与设备的人设选项尚未共用同一份状态，需要另行确认这一流程的实现范围。
- 不同机器的配置是否分别保存、跨页面是否保留，应在下一轮交互验收中明确。
- 首页卡片跳转、有效／废弃标记、充值与凭证流程问题继续保留在原走查清单中，不借此改动现有表头和按钮。

## 5. 实施与验收边界

当前用户端样式由基础样式、布局样式和 `element-client-theme.css` 中的 Element Plus 主题适配组成。Tailwind 扫描包含 Vue 文件；按钮组统一使用容器间距，避免叠加组件默认 margin。管理端和视频生成代码不做改版。

验收重点：

1. 平台名称仍为“虚拟人管理平台”。机器管理表头仍为“名称、mac地址、机器码、密钥、状态”。
2. 设备控制与设备配置共用一个“设备配置”入口和页头；其余菜单、按钮、标签页、表单字段和页面文字与修改前一致。
3. 机器列表在不同视口下按百分比变化，仅在窄屏触及最小宽度。
4. 通用设置不会遮挡原有控件；场景配置窄屏时可以上下滚动查看。
5. 表格、输入、按钮和弹窗保持一致的尺寸、圆角、字号及对齐。
6. 构建通过，已有点击、输入、弹窗打开与取消流程仍可用。

### 设备配置任务顺序（2026-10-14）

设备配置由左右控制/配置并排改为按任务顺序排列：顶部当前机器及原生效提示，人设与音色当前选择摘要（宽屏并排、窄屏上下），返回内容/系统音量/语音控制集中排列，其后为模式选择与底部设备控制。取消原有重复外层卡片，模式选项最小88px高且四周16px内边距、配置卡片统一20px内边距、维护按钮32px高。人设/音色选择大弹窗及原保存、生效行为保持不变。
