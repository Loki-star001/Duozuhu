# 场景配置画布

## 画布与素材

- 画布按宽度／高度等比适配预览区，默认1080×1920；读取机器的screenWidth/screenHeight（有值时），用户调整的尺寸按机器保存。
- 不拉伸画布填满整个预览栏；四周保留20px操作空间。
- 人物使用提供图片的透明抠图版本，原始图片保留在scene-presets/person-source.png。
- 背景预设为生成的室内暖光照片；保留纯色、预设颜色及上传背景。
- Logo默认使用平台的/logo.svg，支持恢复预设与上传替换。

## 编辑

- 背景为不可点击的固定画布底层，不参与图层选择或排序；人物、Logo、四个金刚区按钮、多媒体为可编辑图层。背景固定全幅，旧背景排序在加载与保存时移除。
- 点击画布元素或图层行选择；拖动移动，四角手柄缩放。人物和Logo等比缩放。
- 百分比坐标随画布尺寸适配；允许移动到画布外，坐标支持负值及大于100%；右侧数字输入可精确修改。
- 方向键移动选中元素，Shift加方向键以5%步长移动。
- 选中画布元素后使用置顶／上移／下移／置底改变层级，边界操作禁用；下拉选择器可找回画布外或被遮挡的元素。隐藏图层保留位置和顺序。
- 移除左／中快捷布局设置，人物直接在画布中拖动。
- 金刚区每个按钮可配置名称与触发问答／功能指令，保存需两项非空；双击画布按钮也能打开配置。
- 多媒体图片直接预览，视频使用浏览器解码能力预览（编码兼容性依文件而定）。

## 保存与边界

- 按机器ID独立保存场景、图层、素材与历史文件；仅使用自动保存，移除画布预览标题栏、尺寸摘要与手动保存按钮。
- 使用IndexedDB保存上传素材内容，避免临时blob地址刷新失效及localStorage容量不足。
- 切换机器加载其配置；加载期间遮罩阻止误编辑，异步上传不会写入另一台机器。
- 当前属于本地前端原型；保存不代表向实体终端下发。

## 验证记录

已验证人物拖动、手柄等比缩放、图层上移、金刚区必填校验与取消、调整画布尺寸后的比例、刷新恢复、不同机器场景隔离。项目构建通过。

## 紧凑设置区

背景、Logo、金刚区、多媒体采用最右侧分类导航，避免一次展示所有字段。形象选择仍在设备配置中，不在场景页增加形象库。选中元素的坐标与层级操作共用紧凑属性面板。室内暖光预设缩略图32×44px。画布尺寸收纳在默认折叠区。分类栏匹配设置容器高度，内容独立滚动；已检查1280px与1024px窗口宽度无横向溢出。
场景页面外边距统一24px，预览与设置容器间距16px。属性、配置内容、最右侧分类导航合并为一张白色容器，内部20px留白，以分割线区分内容。已验证1280px及1024px窗口下分类栏位于容器内，内容无横向溢出。

## 单个金刚区交互

每个按钮独立enabled开关，关闭只隐藏该按钮，不清空名称、触发内容、位置或层级；重新开启恢复原配置。总开关只控制整个金刚区显隐，不改写单个开关。名称与触发内容可以在配置区直接输入并自动保存，画布同步更新。旧配置缺少enabled时默认开启以保持原显示。已验证单独关闭/开启、其他按钮不受影响、跨页面自动保存及名称实时联动。

## 对话区与字幕区

增加两个独立图层与分类入口：对话区显示当前一问一答，字幕区显示数字人播报文字。两者可分别显隐，拖动、缩放、修改坐标及调整层级；开关与几何数据按机器自动保存。旧场景加载时补全新图层，不重置已有元素。当前使用示例回答；选择有触发内容的金刚区时，预览问题随之变化，未调用真实知识库或语音接口。已验证两者独立开关、对话图层移动和右侧容器无横向溢出。

## 整屏视觉与状态预览（2026-10-19）

新增柔光蓝灰SVG背景预设，原室内暖光与自定义上传保留。终端使用独立scene-screen-theme.css，统一蓝灰文字、淡紫强调、浅色玻璃材质；管理端继续现有Element Plus规范。

“应用整屏样式”明确应用新背景与排版，不改按钮名称、触发内容或显隐开关；已保存布局不因进入页面而自动覆盖。待机展示金刚区和欢迎字幕，提问展示问题及聆听字幕，回答展示当前问答与回答字幕。状态切换只作用于本地预览，不改变持久化开关，不启动录音或调用问答服务；进入或切换机器重置为待机且不默认选中元素。选择隐藏的对话图层会切换到回答预览，选择业务金刚区会切换到待机预览。空多媒体占位仅在选中编辑时出现。

## 可操作交互预览（2026-10-20）

新增“交互预览”入口，使用全页抽屉检查快捷问题、文字输入、模拟按住说话、识别确认、等待、逐段回答、停止、重试、换问题、反馈与结束会话。演示场景可切换未命中、超时、服务不可用、语音不可用；切换会清除本次演示。当前明确使用本地示例文案，不连接真实知识库、录音或语音播报服务。

读取当前机器的素材、按钮内容、开关与层级，背景固定不可选；进入交互预览后点击执行交互，不拖动或修改场景。对话/字幕在运行预览中为固定输入区避让；设备场景坐标保持原值。退出后继续编辑，不将演示记录写进自动保存。会话保留最近六个历史轮次和当前轮次；闲置60秒清屏，末10秒可继续使用；结束和关闭都取消在途结果。

调研来源、功能矩阵和接口约定见 [数字人大屏交互调研](DIGITAL_HUMAN_INTERACTION_RESEARCH.md)；验证证据见 [交互走查记录](DIGITAL_HUMAN_INTERACTION_QA.md)。
